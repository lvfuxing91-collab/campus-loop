- 日期：2026-11-23

## 一、完成内容

### 1. 账号与导航闭环

- 新增“账号 → 修改密码”入口和修改密码对话框，校验两次新密码一致后调用现有 `AuthService.changePassword`。
- 菜单与页头的“切换账号”统一走同一清理流程，切换前清空当前用户。
- 主界面切换页签时按组件类型刷新，不再依赖固定页签序号；管理员页签也会重新加载数据。

### 2. 管理员后台完善

- 用户表支持排序与单选，保留启用、停用和禁止停用自身的保护。
- 分类维护支持新增、改名、排序值修改、启用/停用和状态标识。
- 违规物品下架要求填写原因，保证审计记录具有可追溯内容。
- `AdminPanel.refresh()` 对外提供统一刷新入口，避免管理员看到过期数据。

### 3. 完整界面联调

- “我的收藏”新增详情入口和双击查看，满足收藏列表跳转详情的需求。
- 物品详情增加标签、发布者平均评分及评价数量。
- 流转按钮状态提取为 `DealActionState`，对卖家/买家、待确认/已接受/已完成/终态分别控制可用操作。

### 4. GUI 自动化

新增 13 个不依赖显示器的 JUnit 用例，并在 `campus-ui/pom.xml` 固定启用 headless 测试模式：

- `AdminPanelTest`：2 项，覆盖分类字段回填、修改保存和启停。
- `DealActionStateTest`：6 项，覆盖未选中、买卖双方权限、完成和终态按钮状态。
- `TableModelsTest`：5 项，覆盖物品、流转、用户表格的格式化、角色视角、空值和防御性复制。
