## 三、接口或数据结构变更

本轮是首次冻结，无变更。已冻结内容见 `docs/设计/接口契约.md`，变更必须登记在该文档第九节。

需要注意的两处实现约定（供成员 2 参考）：

1. `ItemRepository.search` 对 `keyword` 做了 `LIKE ... ESCAPE '\'` 处理，`%`、`_`、`\` 会被转义；传入的关键词不需要自行转义。
2. `ItemMapper` 查询物品时会 `LEFT JOIN categories` 与 `LEFT JOIN users`，因此返回的 `Item` 一定带有 `categoryName` 与 `ownerNickname`；界面表格直接使用这两个字段。

## 四、已知缺陷与绕过方式

| 缺陷 | 影响 | 绕过方式 |
|---|---|---|
| `DatabaseManager` 是单例，测试中不能为每个用例新建独立数据库 | 多个测试类共用一个库会互相污染 | 同一测试类内用 `@BeforeClass` 建库，`@Before` 先 `DROP TABLE` 再重建（`CampusDatabaseTest` 即如此） |
| `DatabaseManager.execute("PRAGMA foreign_keys = OFF")` 只对当前连接生效 | 跨连接的 PRAGMA 不共享 | 建表与删表操作都通过 `DatabaseManager` 的同一入口执行 |
| SQLite 无原生布尔类型 | 布尔以 0/1 存储 | 映射层统一用 `getInt(...) == 1` 转 boolean |
| 时间以 TEXT 存储 | 字符串比较依赖同格式 | 全部通过 `DateTimes` 格式化，禁止各写各的 |

## 五、给下一棒的验证步骤

在干净环境（已装 JDK 8+，无需装 Maven）依次执行：

```bash
cd campus-loop
./mvnw -q -pl campus-core,campus-dao -am test
```

预期：`campus-dao` 输出 `Tests run: 7, Failures: 0, Errors: 0`。

验证数据库脚本可重建：

```bash
rm -f data/campus.db
./mvnw -q -pl campus-app -am package
java -Dfile.encoding=UTF-8 -jar campus-app/target/campus-loop.jar
```

预期：登录窗口打开；用 `admin / Admin@123` 登录后，"物品检索"页能看到 3 件种子物品（高等数学、罗技 K380、羽毛球拍），"统计报表"页显示用户 3、物品 3、在售 3。

关闭窗口后确认数据库文件已生成：

```bash
ls -l data/campus.db
```

预期：文件存在且大小约 100 KB。

验收人签字后，本分支方可合并进 `main`。
