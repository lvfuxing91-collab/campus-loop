## 三、接口或数据结构变更

无。界面只通过 `UiContext` 暴露的服务接口访问业务层，未直接依赖任何实现类。

需要提醒的一点：`MainFrame` 根据 `context.getCurrentUser().isAdmin()` 决定是否显示管理员页签，因此**登录成功后必须先调用 `context.setCurrentUser(user)` 再创建 `MainFrame`**，否则管理员看不到后台。

## 四、已知缺陷与绕过方式

| 缺陷 | 影响 | 绕过方式 |
|---|---|---|
| Nimbus 外观下部分按钮偏小 | 视觉不统一 | 迭代 4 统一 `UIManager` 字体与内边距 |
| 表格列宽固定 | 长标题被截断 | 已加 `AUTO_RESIZE_LAST_COLUMN`，可拖动列宽 |
| 复制 Jar 到无 JDK 的机器无法运行 | fat jar 只含依赖，不含 JRE | 交付说明中注明需 Java 8+；如需免安装，迭代 4 用 `jlink` 或打包 JRE |
| 首次运行 `mvnw` 需联网下载 Maven 3.9.9 | 无网络环境会失败 | 可改用本机 Maven；`~/.m2` 已有缓存的机器直接用 `mvn` |
| 控制台出现 SLF4J NOP 提示 | 无实际影响，SQLite 驱动的日志绑定缺失 | 迭代 2 引入 `slf4j-simple` 或忽略 |
