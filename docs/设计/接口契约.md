# 接口契约

> 状态：迭代 1 冻结（2026-11-04）
> 约定：任何签名变更必须先在本文登记，再改代码。

## 一、契约范围

冻结内容：`edu.campusloop.core` 下的实体字段、枚举取值、仓储接口、服务接口。实现类可以自由重构，但不得改变这些签名。

## 二、枚举

| 枚举 | 取值 | 说明 |
|---|---|---|
| `Role` | `STUDENT`、`ADMIN` | 用户角色 |
| `ItemStatus` | `ON_SALE`、`RESERVED`、`COMPLETED`、`OFF_SHELF` | 物品状态 |
| `TradeType` | `SELL`、`FREE`、`EXCHANGE` | 交易方式 |
| `DealStatus` | `PENDING`、`ACCEPTED`、`COMPLETED`、`CANCELLED`、`REJECTED` | 流转状态 |
| `ItemCondition` | `NEW`、`ALMOST_NEW`、`GOOD`、`FAIR` | 成色 |
| `ItemSortType` | `LATEST`、`PRICE_ASC`、`PRICE_DESC`、`HOTTEST` | 排序方式 |

所有枚举提供 `getDisplayName()` 与中文 `toString()`，界面直接展示中文，数据库存枚举名。

## 三、实体

| 类 | 关键字段 | 不变量 |
|---|---|---|
| `User` | id, username, passwordHash, salt, nickname, role, creditScore, enabled, createdAt | `username` 非空且唯一；`creditScore` 初始 100 |
| `Item` | id, ownerId, categoryId, title, description, conditionLevel, tradeType, price, status, tags, imagePath, viewCount, createdAt, updatedAt, categoryName, ownerNickname | `price` ≥ 0；`FREE`/`EXCHANGE` 时价格为 0；`categoryName`/`ownerNickname` 为查询补充字段 |
| `Category` | id, name, parentId, sortOrder, enabled | `name` 非空且唯一 |
| `Favorite` | userId, itemId, createdAt | 联合唯一 |
| `Deal` | id, itemId, buyerId, sellerId, type, message, status, createdAt, completedAt | `buyerId != sellerId` |
| `Review` | id, dealId, reviewerId, revieweeId, rating, comment, createdAt | `rating ∈ [1,5]`；同一 `(dealId, reviewerId)` 唯一 |
| `OperationLog` | id, userId, action, detail, createdAt | `action` 使用常量，禁止自由文本 |
| `CarbonFactor` | categoryId, kgCo2Saved | `kgCo2Saved` ≥ 0 |
| `StatsReport` | totalUsers, totalItems, onSaleItems, completedDeals, totalCarbonSaved, categoryCounts | 只读汇总对象 |

## 六、查询对象

`ItemQuery` 使用建造者构造，字段全部可选：

```java
ItemQuery query = ItemQuery.builder()
        .keyword("键盘")          // 匹配标题、描述、标签
        .categoryId(2L)           // 分类过滤
        .status(ItemStatus.ON_SALE)
        .sort(ItemSortType.PRICE_DESC)
        .build();
```

语义约定：

- 未设置的字段不参与过滤
- `keyword` 为空白串时视为未设置
- `keyword` 中的 `%`、`_` 按字面匹配（SQL 使用 `ESCAPE '\'`）
- 默认排序为 `LATEST`（`created_at DESC`）

## 七、错误契约

| 场景 | 抛出 | 调用方处理 |
|---|---|---|
| 输入格式非法 | `ValidationException` | 界面直接展示 message |
| 登录失败 / 账号停用 | `AuthenticationException` | 统一提示"用户名或密码错误"；停用单独提示 |
| 违反业务规则（重复用户名、非法状态跳转、越权操作） | `BusinessRuleException` | 展示 message |
| SQL 执行失败 | `DataAccessException` | 展示"数据操作失败，请稍后重试"，详细堆栈写日志 |
| 目标不存在 | `BusinessRuleException`（message 含"不存在"） | 提示并刷新列表 |

约定：`AppException` 的 `message` 一律为可直接展示的中文，不拼接 SQL 或堆栈。
