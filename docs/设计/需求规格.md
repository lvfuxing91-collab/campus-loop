# 需求规格说明书

> 系统：低碳校园资源循环流转桌面系统（campus-loop）
> 版本：v0.1（迭代 1 冻结）

## 一、系统目标

面向校园场景，为师生提供一个"闲置物品发布—检索—流转—评价"的桌面系统。系统以"低碳减排"为落脚点：每一次物品的再利用都按分类系数折算二氧化碳减排量，并在统计页展示。

系统为单机桌面应用：Java Swing 界面、SQLite 本地数据库、无需服务器即可运行。

## 二、用户角色

| 角色 | 说明 | 主要权限 |
|---|---|---|
| 游客 | 未登录用户 | 无（本系统要求登录后使用） |
| 学生（STUDENT） | 普通用户 | 发布/下架自己的物品、检索、收藏、发起流转、评价 |
| 管理员（ADMIN） | 平台维护者 | 学生全部权限 + 用户管理、分类维护、违规物品下架、查看统计 |

## 三、功能需求

### FR-1 账号与认证

| 编号 | 需求 | 验收要点 |
|---|---|---|
| FR-1.1 | 用户注册 | 用户名 3~20 位、字母/数字/下划线；密码至少 6 位且含数字；昵称非空；用户名唯一 |
| FR-1.2 | 用户登录 | 用户名 + 密码；密码错误、账号停用时给出明确提示，且不暴露"用户是否存在" |
| FR-1.3 | 密码存储 | SHA-256(盐 + 明文)，每个用户独立随机盐，数据库中不出现明文 |
| FR-1.4 | 修改密码 | 需校验原密码；修改后旧密码立即失效 |
| FR-1.5 | 账号停用 | 管理员可停用/启用账号；停用账号无法登录，历史数据保留 |

### FR-2 物品管理

| 编号 | 需求 | 验收要点 |
|---|---|---|
| FR-2.1 | 发布物品 | 必填：名称、分类、交易方式（出售/赠送/交换）、成色；出售时必须填价格且不为负 |
| FR-2.2 | 修改物品 | 仅本人或管理员可改；已成交物品不可改 |
| FR-2.3 | 下架物品 | 本人或管理员可下架；下架后不在检索结果中出现 |
| FR-2.4 | 物品状态 | 在售 / 预订中 / 已成交 / 已下架，状态流转受规则约束 |
| FR-2.5 | 浏览次数 | 每次查看详情累加，用于按热度排序 |

### FR-3 检索与浏览

| 编号 | 需求 | 验收要点 |
|---|---|---|
| FR-3.1 | 关键词检索 | 匹配名称、描述、标签；大小写不敏感；`%` `_` 等通配符按字面处理 |
| FR-3.2 | 分类筛选 | 按分类过滤，可与其他条件组合 |
| FR-3.3 | 排序 | 最新发布、价格从低到高/从高到低、热度（浏览量） |
| FR-3.4 | 组合查询 | 关键词 + 分类 + 排序可同时生效 |
| FR-3.5 | 结果展示 | 表格展示编号、名称、分类、交易方式、成色、价格、状态、发布者、浏览量、发布时间 |

### FR-4 收藏

| 编号 | 需求 | 验收要点 |
|---|---|---|
| FR-4.1 | 收藏物品 | 同一用户对同一物品只能收藏一次（联合主键约束） |
| FR-4.2 | 取消收藏 | 取消后不再出现在"我的收藏" |
| FR-4.3 | 收藏列表 | 展示已收藏物品，可跳转到详情 |

### FR-5 流转（交易）

| 编号 | 需求 | 验收要点 |
|---|---|---|
| FR-5.1 | 发起意向 | 买家对在售物品发起意向，可附留言；不能对自己的物品发起 |
| FR-5.2 | 接受/拒绝 | 卖家可选择接受或拒绝某条意向 |
| FR-5.3 | 完成流转 | 卖家确认成交后物品状态变为"已成交" |
| FR-5.4 | 取消 | 未完成的意向可由任一方取消 |
| FR-5.5 | 状态机 | 意向中 → 已接受 → 已完成 / 已取消，非法跳转必须被拒绝 |
| FR-5.6 | 流转记录 | 用户在"流转记录"页查看与自己相关的全部记录 |

### FR-6 评价与信用

| 编号 | 需求 | 验收要点 |
|---|---|---|
| FR-6.1 | 互评 | 一次成交后，买卖双方各可评价一次，评分 1~5 星，可附评论 |
| FR-6.2 | 信用分 | 信用分由历史评价计算（策略可在迭代 4 替换），初始 100 分 |
| FR-6.3 | 评价展示 | 在物品详情与用户信息中展示平均分 |

### FR-7 统计与低碳

| 编号 | 需求 | 验收要点 |
|---|---|---|
| FR-7.1 | 平台概览 | 用户总数、物品总数、在售数、已完成流转数 |
| FR-7.2 | 分类分布 | 各分类物品数量 |
| FR-7.3 | 碳减排估算 | 已成交物品按分类系数（kg CO₂/kg 或件）折算总量 |
| FR-7.4 | CSV 导出 | 导出统计结果为 UTF-8 BOM 的 CSV，Excel 可直接打开不乱码 |

### FR-8 管理员后台

| 编号 | 需求 | 验收要点 |
|---|---|---|
| FR-8.1 | 用户管理 | 查看用户列表、启用/停用账号 |
| FR-8.2 | 分类维护 | 新增、改名、启用/停用分类 |
| FR-8.3 | 违规物品 | 下架任意物品，记录操作原因 |
| FR-8.4 | 操作日志 | 关键操作写入 `operation_logs`，可追溯 |

## 四、非功能需求

| 编号 | 需求 | 指标 |
|---|---|---|
| NFR-1 | 可运行性 | 双击 `campus-loop.jar` 即可启动，无需安装数据库或服务器 |
| NFR-2 | 兼容性 | Java 8 及以上；Windows 10/11 为主，Linux/macOS 可运行 |
| NFR-3 | 响应时间 | 单次检索（万级数据）< 500 ms；启动 < 3 s |
| NFR-4 | 数据一致性 | 写操作使用事务；外键约束启用；失败回滚 |
| NFR-5 | 健壮性 | 非法输入被拦截并给出中文提示；数据库文件缺失可自动重建 |
| NFR-6 | 中文支持 | 界面与数据全 UTF-8；CSV 导出带 BOM |
| NFR-7 | 可维护性 | 分层清晰，模块单向依赖；关键决策在文档中可查 |
| NFR-8 | 可测试性 | 业务层依赖接口而非实现，可注入伪造仓储做单元测试 |

## 五、约束

- 语言：Java 8
- 界面：Swing（WindowBuilder 可打开）
- 数据库：SQLite 3，通过 JDBC 访问
- 构建：Maven 多模块，提供 Maven Wrapper
- 测试：JUnit 4
- 交付：源码、可执行 Jar、数据库脚本、文档、PPT、演示视频

## 七、术语

| 术语 | 含义 |
|---|---|
| 流转 | 物品从原持有人转移到新持有人的全过程，包括意向、接受、完成 |
| 意向 | 买家对某件物品表达的获取意愿 |
| 碳减排估算 | 物品被再利用时，按分类系数折算的等效 CO₂ 减排量 |
| 信用分 | 由历史评价计算出的用户可信度指标，初始 100 |
